# Security policy

## Supported versions

Only the latest version published to npm receives security updates.

## Reporting a vulnerability

Please do not open a public issue for suspected vulnerabilities. Use GitHub's private vulnerability reporting for this repository, or email [gautamvhavle@gmail.com](mailto:gautamvhavle@gmail.com) with:

- A clear description of the issue
- Steps to reproduce it
- The affected version and environment
- Any suggested mitigation

Please avoid accessing data that does not belong to you, disrupting services, or publicly disclosing the issue before a fix is available.

You can expect an acknowledgement within 72 hours and a status update after the report has been assessed.
